# Data Correction

## Purpose

Correct the outputs of the markitdown package.

## Task

The markitdown package often produces garbled outputs when processing certain types of files like PDFs.
This includes issues such as things being accidentally converted into tables or including metadata that is clearly not the content of the document.

Your goal is to fix those kinds of problems, leaving only the content of the files. You should also remove any unnecessary formatting or metadata that is not relevant to the content.
